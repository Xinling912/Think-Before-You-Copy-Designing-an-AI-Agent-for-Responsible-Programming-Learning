# Study materials

This directory follows the three-stage structure of the project's OSF archive:

1. [`01-formative-study/`](01-formative-study/) — questionnaire, analysis code,
   and public aggregate findings used to derive the design requirements;
2. [`02-eviagent-system/`](02-eviagent-system/) — a map to the runnable system
   implementation in this repository;
3. [`03-pilot-study/`](03-pilot-study/) — pilot protocol, questionnaire,
   analysis code, and public aggregate findings.

The corresponding OSF project is available to authorized viewers at
[osf.io/fuvkd](https://osf.io/fuvkd/overview). OSF is the research archive;
GitHub is the curated, runnable portfolio record.

## Public-data boundary

This public repository does not mirror participant-level questionnaire exports,
open-text responses, qualitative coding workbooks containing response text, or
the small-sample pilot archive. It includes study instruments, methods, analysis
code, aggregate tables, and figures sufficient to document the research process
without unnecessarily exposing participant material.

No API keys, live collection endpoints, local databases, names, or contact
details are included. Questionnaire frontends are archival snapshots only.
