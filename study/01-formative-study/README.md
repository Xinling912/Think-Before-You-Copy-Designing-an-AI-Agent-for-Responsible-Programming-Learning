# 01 Formative Study

The formative study investigated how university students use AI tools for
programming, what risks they perceive, and what support they want from a
learning-oriented agent. It collected 72 questionnaire submissions; the
reported quantitative analysis uses 40 complete cases.

## Public materials

- [`original-questionnaire/`](original-questionnaire/) — bilingual source
  questionnaire and a static snapshot of the questionnaire interface;
- [`analysis-script/`](analysis-script/) — Python workflow and dependencies for
  reproducing the quantitative summaries when an authorized input export is
  supplied;
- [`analysis-result/`](analysis-result/) — aggregate tables, descriptive report,
  Likert figures, and a privacy-preserving thematic summary.

The participant-level exports and qualitative workbook remain in the private
OSF research archive. They are intentionally not mirrored to public GitHub
because they contain open-text responses, even though direct identifiers were
removed.
