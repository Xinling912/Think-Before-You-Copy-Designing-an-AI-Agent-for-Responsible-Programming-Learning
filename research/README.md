# Research artefacts

This folder contains the compact, public-facing research record for EviAgent. Materials were selected from the project's OSF-ready archive and local analysis outputs.

## Formative study

`formative-study/` includes:

- the bilingual questionnaire source and static web snapshot;
- aggregate descriptive and Likert results;
- audited figure inputs;
- the analysis script and environment requirements.

The public repository intentionally omits participant-level questionnaire exports and qualitative coding workbooks. The analysis script therefore documents the computational workflow, while the included aggregate outputs provide the portfolio-level result record. The archived research package is available on [OSF](https://osf.io/fuvkd/overview).

## Pilot study

`pilot-study/` includes:

- the study plan and bilingual questionnaire;
- the static questionnaire interface snapshot;
- aggregate rating summaries and figures;
- the analysis script and notes.

Participant-level pilot exports are not mirrored here because the sample is small. Reported findings are descriptive and should not be interpreted as evidence of causal learning gains.

## Privacy and credentials

This public selection contains no API keys, live collection endpoints, names, email addresses, or local runtime databases. Questionnaire frontends are archival snapshots and are not connected to the original research database.
