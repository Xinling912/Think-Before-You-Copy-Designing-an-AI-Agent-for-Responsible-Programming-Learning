# 来源与许可说明

## 1. Education Agent Skills Library

本项目参考：

```text
GarethManning/education-agent-skills
https://github.com/GarethManning/education-agent-skills
```

该库包含 165 个 evidence-based pedagogical skills，覆盖教师设计、课程评估、AI literacy、memory learning science、student-facing learning 等多个教育领域。

MVP 重点参考 `student-learning` 域中的 5 个 skill：

- `retrieve-first-gate`
- `progressive-hint-ladder`
- `stuck-and-error-diagnosis-coach`
- `confidence-calibration-check`
- `teach-back-evaluator`

本项目当前阶段不复制该仓库的全部 skill 内容，而是建立候选清单，并基于项目场景编写适配版 skill 规格。

## 2. 许可处理

原项目使用 CC BY-SA 4.0。直接复制、改写或分发原 skill 内容时，需要保留署名并遵守相同方式共享要求。

ResponsibleEduAgent 当前文档阶段采用以下处理方式：

1. 在文档中明确标注来源；
2. 不全量复制 165 个 skill 的正文；
3. 只列出 skill 名称、路径和评审状态；
4. MVP skill 采用项目内重新表述的规格；
5. 后续若复制原文，需要补充完整 attribution 和许可证说明。
